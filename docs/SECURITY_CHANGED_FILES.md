# Fichiers du chantier sécurité

Cette copie ne contient pas de métadonnées Git utilisables : aucune comparaison de commit ni attribution à un historique distant ne peut être certifiée. Cet inventaire recense les fichiers réécrits/ajoutés identifiés par leur horodatage depuis le début du chantier et les configurations modifiées. Certains fichiers Python ont seulement reçu la normalisation Ruff. Il exclut venv, caches, binaires compilés, logs et secrets runtime. Les GLB fournis sont inchangés.
